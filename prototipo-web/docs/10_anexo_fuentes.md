| Archivo | Contenido |
|---|---|

| `fuentes/Matriz_Riesgos_Actualizada.xlsx` | Registro de riesgos revisado |
| `fuentes/Tabla_Trazabilidad.xlsx` | Trazabilidad HU → modelo → prueba → código |
| `docs/adr/*.md` | Las seis ADR |
| `repo/` | Código del prototipo, pruebas y pipeline de CI (el mismo del repositorio de GitHub) |
